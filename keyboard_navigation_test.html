Keyboard Shortcuts

Try these keyboard shortcuts:

  • Alt + H - Go to Home
  • Alt + D - Go to Dashboard
  • Ctrl + K - Focus Search
  • Alt + Q - Open Quick Actions
  • Alt + 1-4 - Trigger Quick Actions
  • Escape - Close Modal
  • Shift + ? - Show Help
  • F1 - Show Help

Use Tab and Shift + Tab to navigate between elements.
